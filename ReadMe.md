# FPSDemo

第一人称生存射击 Demo。在 15×15 的露天竞技场里活过三分钟的怪潮就能通关。
运行Run文件夹下的FPSDemo_Release_x64.exe即可游玩（解压playable.zip亦可）

---

## 主菜单

方向键 **上 / 下** 切换选项，**空格** 确认，**ESC** 退出。

| 选项 | 作用 |
| --- | --- |
| PLAY | 开始一局 |
| SETTINGS | 音量与键位 |
| QUIT | 退出游戏 |

键位可在 SETTINGS → Keybind 里改。下面写的是默认键。

---

## 你要干什么

1. **上场**  
   出生在场地正中，面朝北方洞穴。西南角有商店，东南角有斜坡接到环廊。

2. **开枪打掉 1×1 方块**  
   沿斜坡或环廊走到北侧廊桥。桥上有一块 1×1 的启动方块。用任意武器打中它，方块会碎掉，倒计时 `3 / 2 / 1 / SURVIVE` 后战斗开始。打之前可以先熟悉移动、武器和商店。

3. **活过 3 分钟**  
   恶魔从北洞往外涌。击杀给钱，用钱在商店补血、补弹。任意时刻死亡即失败。

4. **扛过overtime**  
   三分钟到点后进入 overtime，再刷出最后一大波（40 只）。刷完后不再出怪。把场上剩余恶魔全部打死即胜利。

- **胜利**：ESC 回主菜单  
- **失败**：空格重开一局，ESC 回主菜单  

局中按 ESC 也会回主菜单。

---

## 场地

- **地面**：15×15，四周高墙，内侧一圈宽 2 的环廊（高度 3）。
- **斜坡**：东南，从地面接到南廊。
- **洞穴**：正北，恶魔从这里出来。
- **启动方块**：北廊桥上的 1×1 方块，打中后摧毁并开局。
- **商店**：西南角 2×2 摊位。脚下有红色圆盘，走进范围才会出现购买提示。

---

## 战斗

玩家 100 血。恶魔 100 血，近战约 3 伤害。击杀一只得 **$5**。

开局两把枪：

| 武器 | 切换 | 主攻击 | 副攻击 |
| --- | --- | --- | --- |
| 手枪 | `1` | 射线，25 伤，射程 12，弹匣 20 / 备弹 100 | 无 |
| 等离子步枪 | `2` | 按住蓄力 0.6 秒后松手发射；耗弹 10；直击 20，溅射 25（半径 1.5） | 刺刀，8 伤，近距离扇形 |

滚轮也可切枪。没子弹时按 `R` 换弹。

建议：手枪点名，等离子清堆。商店补的是备弹，换弹后才能打出去。

---

## 商店

走进西南角红圈后，屏幕上方会出现两行提示：

| 键 | 商品 | 价格 | 效果 |
| --- | --- | --- | --- |
| Q | 治疗 | $100 | 回复 20 HP（满血买不了） |
| E | 弹药 | $80 | 每把有弹匣的枪各加 2 个弹匣的备弹 |

钱不够或用不上时，左上角会有短提示。

## 键位（默认）

可在 SETTINGS → Keybind 修改。

### 菜单

| 操作 | 键 |
| --- | --- |
| 上下选择 | 方向键 ↑ ↓ |
| 确认 / 开始 | 空格 |
| 取消 / 返回 / 退出 | ESC |
| 失败后重试 | 空格 |

### 游戏

| 操作 | 键 |
| --- | --- |
| 移动 | W A S D |
| 视角 | 鼠标 |
| 跳跃 | 空格 |
| 主攻击 / 蓄力 | 鼠标左键 |
| 副攻击（等离子刺刀） | 鼠标右键 |
| 手枪 | 1 |
| 等离子步枪 | 2 |
| 上一把 / 下一把 | 滚轮上 / 下 |
| 换弹 | R |
| 商店治疗 | Q |
| 商店补弹 | E |
| 返回主菜单 | ESC |

鼠标左键对等离子是按住蓄力、松手发射。点按不会出球。

## 控制台（可选）

按 `` ` ``（波浪键）打开开发控制台。

| 命令 | 作用 |
| --- | --- |
| `god` | 切换玩家无敌 |
| `killall` | 立刻杀死场上全部恶魔 |

其它：`F1` 开关调试绘制，`P` 暂停游戏时钟，`T` 按住慢动作，`O` 单帧步进，`F8` 重启到主菜单。
